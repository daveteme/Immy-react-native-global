Immy - Community App for Ethiopians and Eritreans in the DMV
Immy is a mobile application designed to serve the Ethiopian and Eritrean communities residing in the DMV (District of Columbia, Maryland, Virginia) area and beyond. This app provides a platform for users to connect, share information, and engage with their local community.
Key Features

Multilingual Support: Immy offers three language options - English, Amharic, and Tigrinya - catering to the diverse linguistic needs of the target audience.
Registration and Account Creation: Users can sign up and create their own accounts, enabling personalized experiences and community engagement.
Bottom Navigation: The app features a bottom navigation bar with five main sections:

Rent: Users can post and browse rental listings.
Ad: Users can create and view advertisements.
Event: Users can share and discover local events.
Jobs: Users can post and search for job opportunities.
Profile: Users can manage their account settings and view their activity.


Robust Functionality: Immy is built on a solid Redux foundation, ensuring a well-organized and scalable codebase.

Target Audience and Objectives
Immy is designed to cater to the needs of the Ethiopian and Eritrean communities in the DMV area, as well as those who have connections to these communities across the globe. The primary objectives of the app are:

Community Engagement: Provide a platform for users to connect, share information, and foster a sense of community among Ethiopians and Eritreans.
Information Sharing: Enable users to post and access a wide range of content, including rental listings, advertisements, event information, and job opportunities.
Localization and Accessibility: Ensure the app is accessible and user-friendly for individuals with diverse linguistic backgrounds through the multilingual support.
Scalability and Sustainability: Build the app on a robust technical foundation to support future growth and expansion.

Technologies and Frameworks
Immy is developed using the following technologies and frameworks:

React Native: A popular framework for building native mobile applications using JavaScript and React.
Redux: A predictable state container for JavaScript applications, ensuring a well-structured and scalable codebase.
React Navigation: A library for handling navigation in React Native applications.
i18next: A popular internationalization framework for React, enabling seamless language support.
Expo: A toolchain built around React Native, simplifying the development and deployment process.
